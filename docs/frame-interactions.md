# 画框材质与鱼获翻转

设计日期：2026-09-16。用户要求第二、三屏画框提升质感，第三屏悬停翻到真实鱼获，点击画框放大并展示钓获信息。保留前序要求：简洁、照片不裁切、无碎文案、心愿单同款只加未解锁印章。

## 真实参考

- [MOEBE Frame](https://moebe.dk/products/frame)：窄木条、橡木/烟熏橡木等材料与双面展示思路。借鉴轻薄结构，不复制商标、商品照片或独有的橡皮筋结构。
- [Jackson’s Frame Builder](https://www.jacksonsart.com/frame-builder)：Natural Oak 窄边木框和 shadow gap 等装裱结构。借鉴边缘深度与作品内嵌的关系。

选用窄烟熏橡木、米色卡纸、45°拼角、很浅的斜面亮暗和墙面投影。保持第二屏原有两张在上、一张在下的排布。第三屏正面是鱼图和名称；反面只放真实鱼获，不增加说明文字。

## 交互实现

- `FieldFrame` / `FrameRails` 统一第二屏照片、鱼种卡正反面、心愿单与打开后的详情画框。
- 鼠标进入时约 700ms 绕竖轴翻转；离开后恢复。Escape 可取消悬停预览。
- 已有真实照片的六种鱼显示自己的首张鱼获；无照片的重口裂腹鱼、齐口裂腹鱼、北极茴鱼保持图标，避免伪造图片。
- 翻转反面按真实图片宽高计算尺寸，以卡片宽度和视口高度为上限，不裁切、不拉伸；浮在原卡位置，避免整张网格上下跳动。
- 鼠标点击或键盘激活直接打开详情。触屏首次点击翻面，再点打开；失焦取消触屏预览。
- 详情通过原卡片的位置和大小进行展开动画。保留键盘关闭、焦点管理、切换照片、真实笔记日期和地区。缺失字段不显示重复占位文字。
- 弹窗照片宽高属性来自实测文件像素尺寸，CSS 使用 auto 和视口上限，避免原来的统一 1600×1200 假比例。
- 减少动态效果或站内暂停动效时，使用即时切换，不执行空间翻转和放大动画。
