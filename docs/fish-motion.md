# 透景背景与鱼种游动（2026-09-16）

用户要求第三屏延续首屏、第二屏的透明感，放大鱼种图标并增加游动。

- 共用山水背景延续至图鉴和心愿单；滚动纸色遮罩最高 54%，夜景 76%，保留景深和深色标题的可读性。
- 图标正面的内衬改为半透明渐变，框与真实鱼获背面、详情交互保留。
- 鱼种展示使用已有透明底图片，识别 alpha 有效边界后按框内可用空间等比例呈现，不改写原始图片。主体更大，留出游动边距。
- Canvas 将原图细分成相邻图像条带，以尾部为主产生渐增的波动，头部保持稳定，附加低幅水平与垂直位移。各鱼种起始相位不同，最多 30 fps，像素比上限 2。
- 离开视口、后台标签页、翻到真实照片时停止动画；系统减少动态效果偏好下保持静态，加载期间或 Canvas 不可用时仍有原图。
- 图标保持装饰语义，鱼名仍由文字表达，无新文案或控件。

类型检查、CSS 解析及生产构建通过；浏览器视觉/交互尚未验证。修改在当前可写 website-preview 副本，原项目及旧预览尚未同步。
